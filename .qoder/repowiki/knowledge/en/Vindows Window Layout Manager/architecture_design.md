The app is a single WPF project (Vindows.csproj) whose UI lives in App.xaml/MainWindow.xaml and code-behind, while the Core/ directory provides the domain layer: Models.cs defines shared data contracts (zones, layouts), Win32.cs and WindowEnumerator.cs enumerate processes and their native window handles via P/Invoke, LayoutStore.cs persists zone definitions, and LayoutApplier.cs drives the actual SetWindowPos calls to move windows into their assigned zones. The UI binds to view models (e.g. ZoneVM.cs) that orchestrate these Core services, keeping all interop and persistence behind the Core boundary.
